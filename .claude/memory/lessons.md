## Lessons

- 1. 2026-08-17 — Base UI orientation variants not generated by shadcn init → After `shadcn init --base base`, manually add `@custom-variant data-horizontal` and `@custom-variant data-vertical` to `globals.css` — any Base UI component using orientation-based Tailwind variants silently fails without them.
- 2. 2026-08-18 — Read the library source before guessing at bugs → When a UI primitive behaves unexpectedly, read the source before making any code change. One wrong fix is understandable. Two wrong fixes means stop and read the source. Framework internals are rarely more than 50–100 lines and always contain the answer. (Root cause here: Base UI `hasNullItemLabel()` false-positived on items lacking a `value` property, suppressing the placeholder.)
